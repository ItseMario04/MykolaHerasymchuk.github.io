Data cleaning in Python and Tableau visualization

Customer's Task

I would like to purchase a property in Valencia, Spain, to rent it out. It`s should be possible to determine whether it would be worthwhile to pay extra for a property with more rooms, or whether the additional cost would not be justified. I would also like to find out how much rooms are rented for in different parts of the city. Additionally, i would like to analyze the number of bookings per host to understand how many bookings I can expect as a potential host.

Where to find data?

To find required data we could use the Inside Airbnb dataset for Valencia, Spain. It`s usefull because this dataset official from Airbnb and regularly updated. For our purposes we will download the detailed Listings, Calendar and Review data in csv format. Other data acquisition methods include data scraping and API extraction. Examples of these methods can be found at the link.

Opening the DataSet

Usualy in data analitics we are working with .txt, .csv and .json files format and most of the software supports these formats. Sometimes data set is not compiling automaticly, so that why we should specify: field separator (delimiter) is usualy a comma (,); encoding 65001: Unicode (UTF-8); text qualifier is usualy double quotes ("); Regional settings for decimal separator.

MySQL

The pandas library in Python is highly flexible and can automatically overlook or correct minor CSV syntax errors, whereas traditional parsers (such as those in MySQL Workbench or older versions of Excel) fail immediately.

If you simply load that same CSV file into MySQL Workbench or older versions of Excel, you will notice that the file fails to parse correctly after the fourth row, or the formatting breaks (the data "shifts") in the case of Excel. We can use Notepad++ to identify the issue. First, we can check the file's encoding in the bottom-right corner. Second, by enabling the "View → Show Symbol → Show All Characters" option, we can see CR LF or LF markers, which should only appear at the end of a line. If CR LF markers appear in the middle of an address or comment - that is the cause of the line breaks.

In other projects we will use MS SQL or Google BigQuery where this will no longer be an issue but for now let see the execution in MySQL Workbench. The standard MySQL Workbench GUI wizard cannot handle this file. You need to use the direct "LOAD DATA INFILE" SQL query, but first, you must replace all internal line breaks with spaces or tags using Python.

# Python
import pandas as pd
df = pd.read_csv(r'D:\Data_Analytics\MySQL\Portfolio\listings.csv', low_memory=False)
df = df.replace(r'[\r\n]+', ' ', regex=True)
df.to_csv(r'D:\Data_Analytics\MySQL\Portfolio\listings_for_mysql.csv', 
index=False, encoding='utf-8', quoting=1)
