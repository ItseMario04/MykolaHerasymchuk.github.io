Scraping Data from Wikipedia

Project Overview

Data scraping is the process of extracting structured information from web pages and converting it into a format suitable for further analysis. This is a useful skill for a data analyst because valuable datasets are not always available through ready-to-use APIs or downloadable files, making web scraping an effective way to collect data from publicly available sources.

Project Goal and Value

In this project, I used the BeautifulSoup Python library to parse HTML and extract relevant data from a web page. As a practical example, the project includes Python code for extracting and cleaning a structured table directly from a Wikipedia page, preparing it for subsequent analysis.

Python

For this task, I will use the BeautifulSoup library in Python. The Jupyter Notebook interactive development environment was used for this task. ".ipynb" file could be found in this GitHub repository
