Excel Dashboard

Customer's Task

For our coffee company, it is important to identify which of our coffee varieties generate the highest demand. We also need to understand our customers—specifically, who is buying and in what quantities—as well as determine where our business is strongest and where we should expand next. Additionally, we would like to express our appreciation to our largest clients.

Excel Dashboard

Excel proficiency is the standard for working with data. The ability to perform data cleaning and Exploratory Data Analysis (EDA), as well as build interactive dashboards, is an essential skill for a data analyst. To demonstrate actual proficiency and an understanding of working with Excel, this project utilized functions such as XLOOKUP, INDEX MATCH, multiplication formulas, and multiple IF functions, alongside skills in date and number formatting and duplicate checking.

This project could be found in the GitHub repository. And also this project was heavily inspired by Mo Chen video.

Description of the Data Analysis Process

Let's go through the data that we'll be working with. This is a dataset on coffee bean sales. We have the Order ID column, Order Date, Customer ID, Product ID, and Quantity already populated. Now, we have a couple of columns, column F to M, where the data is not populated. There are going to be times when the data sits in different tables and you'll have to do lookups to get your data. This is exactly what we'll be doing. We're going to be gathering our data first. We have two other tables: the Customers table and the Products table.

The Customers table contains all of the customer information. The unique key or the primary key here is the Customer ID. Row 2 belongs to a customer named Louisiana Owner, and they have email addresses, phone numbers, address lines, city, country, postcode, and loyalty card status.

Moving on to the next tab, which is the Products table, we have Product ID as the primary key, coffee type, roast type, size, unit price, price per 100 grams, and the profit associated with it. We'll be looking up these values first and then returning to our Orders table.

We'll gather the customer data using the XLOOKUP formula, and then we'll be using the traditional INDEX MATCH to gather the product data. INDEX MATCH in this case will be really good because it will be dynamic. I'll write only one formula for the products that I want to look up, and I'll be able to populate all of the columns, whereas for XLOOKUP I'll actually have to repeat my formula three times: once for customer name, once for email, and once for country.

Click into cell F2 and start typing XLOOKUP. Hit Tab to auto-populate the formula. Select the lookup value, which is Customer ID in cell C2. Then go to the Customers worksheet to select the lookup array, which is the Customer ID column (column A). Select everything using Ctrl+Shift+Down and press F4 to lock in the range with dollar signs. Next, select the return array. For Customer Name, click into cell B2 on the Customers sheet, select down, and press F4 again. Set if_not_found to empty, match mode to exact match (0), close the brackets, and hit enter. Double-click the bottom right corner (the fill handle) of cell F2 to auto-populate all customer names.

For the Email column in cell G2, do the exact same with XLOOKUP. Select Customer ID as the lookup value, the Customer ID column in the Customers table as the lookup array (locked with F4), and column C (Email) as the return array (locked with F4). If there are blank emails, XLOOKUP will return a zero. To fix this, wrap the formula in an IF statement: if the XLOOKUP result equals zero, return an empty string, otherwise return the XLOOKUP value.

For the Country column in cell H2, use XLOOKUP with Customer ID as the lookup value, Customer ID column as the lookup array, and Country column (column G) in the Customers sheet as the return array (locked with F4). Set match mode to exact match (0) and double-click to auto-populate.

Now move on to the product information using INDEX MATCH. Place one dynamic formula in cell I2, then drag it right and down to populate all product columns.

In cell I2, enter INDEX. For the array, select the full dataset range in the Products worksheet and lock it with F4. For the row number, use the MATCH function: match the Product ID from the Orders table (fixing the column reference so it remains on column D) against column A in the Products sheet (locked with F4) with exact match (0). For the column number, use a second MATCH function: match the header name (cell I1 in Orders, locking the row reference to row 1) against the header row in the Products sheet (locked with F4) with exact match (0). Close all brackets and hit Enter. Drag this formula across to populate Roast Type, Size, and Unit Price, then double-click down to populate all rows.

To populate the Sales column in column M, multiply Unit Price by Quantity: = Unit Price * Quantity. Double-click to auto-populate.

Create a new column named Coffee Type Name in column N to convert abbreviated coffee types into full names using nested IF functions: if cell I2 equals "ROB", return "Robusta"; if "EXE", return "Excelsa"; if "ARA", return "Arabica"; if "LIB", return "Liberica". Auto-populate down.

Create another column named Roast Type Name in column O to convert single letters into full roast names using nested IF functions: if cell J2 equals "M", return "Medium"; if "L", return "Light"; if "D", return "Dark". Auto-populate down.

Format the Order Date column (column B) using Custom formatting: select range, press Ctrl+1, choose Custom, and set format to DD-MMM-YYYY.

Format the Size column (column K) to show kilograms: select range, press Ctrl+1, choose Custom, and set format to 0.0 "kg".

Format the Unit Price and Sales columns as currency in US Dollars from the Home tab.

Check for duplicate values: select the entire dataset, go to the Data tab, and click Remove Duplicates.

Convert the range into an Excel Table using the shortcut Ctrl+T. Rename the table to "OrdersTable" under the Table Design tab and choose a clean table style.

Insert a Pivot Table using the shortcut Alt+N+V+T (or Insert > Pivot Table) to begin analysis and build pivot charts for total sales.
