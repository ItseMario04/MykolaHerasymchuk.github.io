Intelligent Data Analysis

Project Overview

Machine learning is an important tool for analyzing data and making predictions based on existing patterns. In this project, I will train and compare several supervised machine learning models using the Materials and their Mechanical Properties dataset. Models will be trained to predict material quality based on their mechanical properties, demonstrating a practical application of machine learning for material analysis and classification.

Project Goal and Value

Machine learning (ML) models were trained using the Materials and their Mechanical Properties dataset obtained from the Autodesk Material Library.

Following standard data cleaning and exploratory data analysis (EDA), a train-test split was performed. The primary objective of training the ML models is to determine material quality based on mechanical properties. Thus, when new mechanical property parameters for a new material are entered, the trained models will be able to predict the quality assessment of that new material.

This problem can also be solved using classical algorithms, but for training purposes, the following ML models were trained and then compared to each other:

  • Decision Tree;
  • K Nearest Neighbors (KNN);
  • Support Vector Machine (SVM);
  • Random Forest (RF);

Python

For this task, I will use the pandas, seaborn, matplotlib.pyplot, sklearn.model_selection, numpy, sklearn.tree, sklearn, sklearn.metrics, sklearn.preprocessing, sklearn.neighbors, sklearn.svm, sklearn.ensemble library in Python. The Jupyter Notebook interactive development environment was used for this task. Raw data and .ipynb files could be found in this GitHub repository
